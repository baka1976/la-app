LA 0-3 음높이 곡선 테스트

la_0-3_pitch-test_v3 · 말하면 높낮이 곡선이 그려집니다. 소음 속에서도 곡선을 읽을 수 있는지 확인하는 페이지입니다.
‘마이크 시작’을 누르면 주변 소음을 잽니다. ‘말하세요’가 나올 때까지 말하지 마세요.

말할 단어

마이크를 켜면 시작합니다
주황 점선 = 기대하는 높낮이 모양 · 파란 선 = 내 곡선(옥타브 오류 보정 후)
귀로 들은 것과 곡선이
순서: ♪높낮이 → ‘삑’ → 말하기 → 결과 소리(딩동 = 기대와 같음, 뚜뚜 = 다름, 낮은 뚜— = 곡선을 못 읽음) → 결과 보는 시간 → 다음 단어. 곡선을 못 읽으면 같은 단어를 다시 냅니다.
‘♪높낮이’는 규칙으로 만든 허밍 소리라 고저 모양이 정확합니다. 기기 음성은 악센트가 틀릴 수 있어 참고만 하세요.
