조사일: 2026-10-25. 규모와 이용 조건 중 직접 확인하지 못한 것은 [미확인]으로 표시.

## 문제를 만들 때 소스를 쓰는 구조

```
[1] 한-일 병렬 구어 데이터   → 문제 원문(한국어) + 1차 답안 후보
[2] 일본어 자연 회화 자료     → 답안이 자연스러운지 검증, 군말·축약 등 구어 특징
[3] 드라마·영화 대본(합법 입수) → 장면, 말투, 감정 표현의 기준
[4] 유행어 목록              → 트렌디한 어휘
[5] 경어 기준                → 격식 단계의 정답 기준
```

## 받은 자료로 문제를 만드는 절차 (Claude가 할 일)
1. AI Hub JSON에서 장면 태그로 거른 뒤 레벨(의미 단위 개수)별로 문장을 뽑는다
2. 한국어 원문이 문어체면 구어로 다듬는다 (원문 변경 사실 표시)
3. 일본어 답안을 번역투 기준으로 점검하고, NUCC 검색이나 대본으로 자연스러운지 확인한다
4. 의미 단위, 함정 어휘, 대안 답안을 붙여 채점 기준을 만든다
5. 라운드별로 테스트 → 피드백 → 소스와 기준 수정
