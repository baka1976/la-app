### 5. 어원 (2026-10-28 방향 결정: 1단계 부연 설명 → 2단계 뿌리 묶음)
- 목적: 「왜 그 뜻인지」를 실마리로 기억에 남기기(사자성어처럼). 어원은 외울 대상이 아니라 단어 뜻·쓰임을 기억하는 수단. 문제는 늘 단어 뜻·쓰임을 묻고 「어원이 무엇인가」는 묻지 않는다.
- 두 종류로 나눈다: ① **구성 풀이**(글자·형태 분석: 目+に+余る, 側(そば)から, 放す→〜っぱなし) — 부분 뜻으로 확인 가능, 사전 대조 후 사용. ② **역사 어원·에피소드** — 여러 설·민간어원이 많고 Claude가 지어내기 쉬운 분야 → 근거(『日本国語大辞典』 語源説 등, kotobank) 있을 때만, 「정설 / 여러 설 / 속설」 표시. 근거 없으면 「Claude 설명 (근거 없음)」, 에피소드는 넣지 않음. 클라우드 세션은 kotobank가 막혀 있음 → 환경 네트워크에서 kotobank.jp 허용 또는 집 PC 세션.
- [ ] **1단계 부연 설명**: 틀림·확신 오답·헷갈림 단어에만(모든 단어 X, 팩 136개 중 관용구·명사/동사에서 온 문형·구성으로 뜻이 보이는 말 위주로 대략 20~30%). 답 확인 뒤 접었다 펴는 「어원」 한두 줄 + 근거 표시. 답 전에는 보여 주지 않음(힌트가 되므로). 내가 틀린 단어로만 쌓이는 개인 자료. LASENT1·단어 카드 데이터에 `etym{type:"구성"|"어원", text, src, grade:"정설"|"여러 설"|"속설"|"근거 없음"}` 같은 필드.
- [ ] **2단계 뿌리 묶음** (어원 20개쯤 쌓이면): 같은 뿌리 말을 묶음으로. 예) 余る: 目に余る(보아 넘길 수 없다)·身に余る(분에 넘치다)·手に余る(감당할 수 없다) / 〜っぱなし: 流しっぱなし·開けっぱなし·出しっぱなし / 〜そばから. 순서: 구성만 보고 뜻 추측해 적기(처음 보는 말도) → 뜻·어원 확인, 묶음 안 비교 → 문장 속에서 듣고 구분(3번 소리 구분 연습과 연결). **추측 문제에는 구성 풀이만**(속설·여러 설은 안 냄). 묶음에 넣는 말도 사전으로 실제 쓰는 결합인지 확인.
- [ ] 자료 후보: 사용자가 기억하는 **몸·명사 기준으로 숙어를 정리한 만화 구성 책**(목·手·口 등 신체어 관용구 책으로 추정) — 사용자가 찾는 중. 찾으면 제목·판권 확인 → 비공개 스캔 → 묶음의 근거·예문으로(저작권 원칙대로 드라이브·기기에만). 닮은꼴 표현 사용법사전도 구별 근거로.

## 0-00. v5.6: 결과지 쓰기형, 헷갈린 단어 문장 확인 (2026-10-28)

  - 테스트: Playwright(가짜 마이크·음성 읽기·중복을 보내는 가짜 음성 인식, v5.0에서는 같은 가짜로 중복이 재현됨)로 연습 탭(듣고 통역 → 답 보기 → 녹음 재생 → 다음 문장 재시작), 핸즈프리, 기기 점검 7항목, 콘솔 오류, 375px 폭 확인.

## 3. 지금까지의 판단 (다시 논의하지 않아도 되는 것)

- **자동 채점의 한계**: 음성 인식은 틀린 말을 맞게 다듬어 적는다 → 오류 찾기에 쓰지 않고, 남는 것(목표 표현·피할 표현·결론 위치)만 본다. 정확성은 녹음 + 포인트 자기 체크 + 주 1회 Claude 채점으로.
- **피드백 순서**: 1차 AI(자동 확인·Claude 채점) → 2차 사용자 확인(녹음 재청취) → 라운드 뒤 문제점 재검토.
- **P-01 한국어가 공문체인 것은 의도** (그 문체를 말로 푸는 것이 훈련 목표). 일상 구어는 H1·C1에서.
- **저작권**: 드라마·애니 대본을 앱에 넣지 않는다. 장면 구조와 유행어 경향만 참고해 대사는 새로 쓴다. 공식 시나리오북은 구입해 개인 참고용으로. 무단 대본·자막 사이트는 쓰지 않는다. 애니 대사는 역할어(〜だぜ 등)를 걸러야 한다.
- 이 앱은 개인 학습용 (사업 목적 아님).

## 4. 남은 과제 (우선순위)

1. v5.1 main 합치기 → 아이폰 기기 점검 ⑥·⑦ 재확인 → 1라운드 테스트 (H1·C1, 🎧 켜고) → 결과지·점검 결과로 문제점 재검토
2. **콘텐츠 양** (가장 큰 약점): 세트당 30문장 이상. 소스는 `docs/sources.md`
   - AI Hub 「일상생활 및 구어체 한-일 번역 병렬 말뭉치」(546), 「방송 콘텐츠 한-일 번역 병렬 말뭉치」(71263): 용량이 커서 **로컬 PC에서** 받아 처리할 예정
   - 받은 뒤: 장면·레벨로 거르기 → 한국어 문어체는 구어로 다듬기 → 일본어 번역투 점검(名大会話コーパス·CEJC 검색으로 확인) → 의미 단위·함정 어휘(kw·ng) 붙여 JSON으로 → 「문제 추가하기」로 넣기 (또는 기본 문항으로 커밋)
3. 처음 사용 흐름: 처음 열면 기기 점검으로 안내하고, 결과에 맞춰 옵션을 자동으로 켜기
4. 재미: C1을 같은 캐릭터가 나오는 이어지는 에피소드로
5. 저장소 정리: 보류된 옛 파일(`la_0-*`, `la_1*`)을 `archive/`로
