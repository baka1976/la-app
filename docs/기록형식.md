# LA 공통 기록 형식 (LAREC1) — 루틴 앱·통역 드릴이 함께 쓰는 오답노트·풀이 기록

2026-11-04. 루틴 앱(`routine.html`)이 쓰는 형식이다. 통역 드릴(`drill.html`)을 심화 앱으로 이어 갈 때 **같은 파일을 읽고 쓰면** 두 앱의 오답노트·기록이 합쳐진다.
이 파일에는 형식만 적는다(실제 기록·교재 문장은 비공개 저장소에만 있음).

## 어디에 있나
- 비공개 GitHub 저장소 `records.json` (Contents API로 받고 올림). 저장소 주소와 토큰은 기기마다 localStorage `la-sync-v1` = `{repo, token, last, err}`.
- 기기 안 사본: localStorage `la-daily-v2`.
- 합치기 규칙: **지우지 않고 더한다.** 같은 항목은 시각(`t`)이 나중인 쪽을 따른다. 올릴 때 sha 충돌(409/422)이면 다시 받아 합친 뒤 최대 3번 올린다.

## 최상위
```json
{"fmt":"LAREC1","at":"ISO 시각",
 "ptr":{}, "wrong":{}, "log":[], "known":[], "notes":{}, "seen":{}, "judges":{}, "hist":[], "ux":[]}
```

| 키 | 내용 | 합치기 |
|---|---|---|
| `ptr` | 영역별 진도 번호(루틴이 다음에 낼 위치) `{영역: 번호}` | 큰 값 |
| `wrong` | 영역별 틀린 문항 id 목록 `{영역: [id…]}` | 합집합, 다시 맞힌 것은 뺌 |
| `log` | 학습 한 번 = 한 줄 `{date, ok, n, kind?}` (kind: `review` 복습, `custom` 골라 풀기, 없으면 오늘 학습) | date·ok·n 같으면 하나 |
| `known` | 「이미 아는 단어」 목록 | 합집합 |
| `notes` | **오답노트** `{키: 항목}` (아래) | 시도(a)를 t로 합침 |
| `seen` | 문항별 마지막 결과 `{"영역\|id": {t, ok}}` | t 나중 |
| `judges` | AI 판정 `{날짜: {t, text}}` | t 나중 |
| `hist` | **풀이 이력**(객관식 한 번 = 한 줄, 난이도 측정용) | t+k+id로 합침, 최근 20000줄 |
| `ux` | 불편·바라는 점 메모 `[{t, text}]` | t로 합침 |
| `tests` | 레벨 테스트 결과 `[{t, date, lv, sc:{lang, read, listen, lang_n, read_n, listen_n}}]` (각 60점 환산) | t로 합침 |
| `wsc` | 쓰기 점수(AI 판정에서 읽음) `{날짜: {t, items:[[문법,문형·의미,자연스러움]…], test}}` 각 0~5 | t 나중 |

## 오답노트 항목 (`notes`)
키: `"영역|문항id"` (주관식처럼 id가 없으면 `"영역|날짜#순번"`)
```json
{"k":"moji","id":"N1-01-03",
 "a":[{"d":"2026-11-04","t":179373818605200,"ok":false,"pick":2,"why":"…","conf":"unsure","ms":13926,"fb":"[정답이 이상해요] …"}],
 "st":{"v":"done","t":1793738186052}}
```
- `a`: 시도 목록. `t`는 `Date.now()*100+순번`(같은 밀리초 구분). 필드: `ok` 정답 여부, `pick` 고른 번호, `picked` 고른 뜻(어휘 카드), `why` 오답 이유, `mine` 내 답(주관식), `q`·`a` 문제·교재 답(번역), `pat` 문형(작문), `conf` 확신도(`sure`/`unsure`), `ms` 걸린 시간, `fb` 질문·오류 메모(「이상해요」 표시는 `[…]`로 시작).
- `st`: 사용자가 「해결로 표시」하면 `{v:"done"}`. 풀기만 하는 쪽은 건드리지 않아도 됨.
- 상태 계산(화면용): 해결 표시 → 해결 / 마지막 시도 뒤 다시 맞힘(seen) → 다시 맞힘 / 틀렸거나 애매 → 미해결 / 그 밖(질문만) → 메모. 복습 화면은 「아직」(미해결·메모)·「알았다」(다시 맞힘·해결) 두 묶음으로 보여 준다.

## 풀이 이력 한 줄 (`hist`)
```json
{"t":1793738186052,"d":"2026-11-04","k":"listen","id":"GS-1-4-1","ok":true,"ms":13926,"c":"unsure","m":"rv"}
```
`c` 확신도(없으면 확실), `m` 풀이 방식(`rv` 복습, `pk` 골라 풀기, `lt` 레벨 테스트, 없으면 오늘 학습).

## 실력 추정(「실력」 탭)
- 영역: 언어지식(moji·gram·tg) · 독해(reading) · 청해(listen). 문항의 책 레벨(lv)별로 따로 계산.
- 복습(rv)을 뺀 풀이 중 영역별 최근 60개, 맞힘 1 · 애매하게 맞힘 0.5 · 틀림 0의 평균 × 60 = 영역 점수(JLPT식 60점 환산). 합계 180, N1 합격선 100·과락 19로 표시.
- 주별 추세는 각 주 끝 시점까지의 같은 계산. 다른 앱이 hist에 같은 형식으로 쌓으면 함께 반영된다.

## 영역 이름 (`k`)
`listen` 청해 · `kanji` 한자 · `moji` 어휘(모의고사) · `gram` 문법(모의고사, seen 키는 `gf`/`so`) · `tg` 글의 문법 · `v5` 어휘 카드 · `p630` 문형 카드 · `reading` 독해 · `ilyeok` 일역 · `hanyeok` 한역 · `write`/`write2` 작문 · `talk` 회화 · `pat`/`pat2` 문형.
통역 드릴이 새 영역을 쓸 때는 겹치지 않는 이름(예: `drill`, `rp`)을 붙이고, 문항 id는 드릴 쪽 문제 팩 id를 쓴다.

## 문제 팩
비공개 저장소 `packs/manifest.json`이 가리키는 `LA_루틴_문제_YYYYMMDD.json`(`{format:"LARTN1", kind:"data", built, data}`)과 음원 팩. 문항 id가 위 기록의 `id`다. 드릴이 같은 문항을 쓰면 같은 id로 기록해 오답노트가 합쳐진다.
