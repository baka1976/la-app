# la-app

LA 외국어 학습 프로젝트 (일본어, S 트랙) 도구 모음.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 시작 화면 (홈 화면·즐겨찾기용). 문제은행은 아티팩트 주소로 연결 |
| `qbank.html` | 문제은행 v2.8 (옛 판, 고치지 않음). 새 주소 안내와 기록 옮기는 방법만 표시. 현재 문제은행은 v2.9 아티팩트(https://claude.ai/artifact/JajEgZVK3ThJzjtsQokLMi, 서버 저장) |
| `drill.html` | 통역 드릴 v4.1 (S3-2) — 말함/막힘, 핸즈프리, 롤플레이, 반응 시간 측정, 음성 인식 목표 표현 확인(실험) |
| `la_0-*`, `la_1-*`, `la_1A_*` | 보류된 앱 트랙(D-17)의 이전 파일. 기록용 |

## 개인정보

- 이 저장소는 공개다. 사용자가 쓴 작문, 오답 드릴 원문, 오류 기록은 **파일에 넣지 않는다.**
- 이 저장소의 도구(통역 드릴, 옛 문제은행) 기록은 각 기기의 브라우저(localStorage)에만 저장된다. 문제은행 v2.9는 claude.ai 아티팩트의 서버 저장(주인만 읽고 씀)을 쓴다.
- 오답 드릴 원문 등은 개인 자료 팩(`LAPK1:` 코드)으로 따로 보관하고(구글 드라이브), 기기에서 불러온다.
- 결과지는 「결과지에서 가릴 말」 목록과 메일·전화번호 형식을 자동으로 가린다.
- 검색엔진 수집 제외: `robots.txt`, `noindex`.
