## 개인정보

- 이 저장소는 공개다. 사용자가 쓴 작문, 오답 드릴 원문, 오류 기록은 **파일에 넣지 않는다.**
- 이 저장소의 도구(통역 드릴, 옛 문제은행) 기록은 각 기기의 브라우저(localStorage)에만 저장된다. 통역 드릴의 녹음은 세션 동안만 메모리에 있고 저장·전송하지 않는다. 「문제 추가하기」로 넣은 문제도 기기에만 저장된다. 문제은행 v3.x는 아티팩트판·GitHub판 모두 사용자의 비공개 구글 시트 「LA 기록」에 저장한다. Apps Script 코드와 토큰은 이 저장소에 두지 않는다.
- 오답 드릴 원문 등은 개인 자료 팩(`LAPK1:` 코드)으로 따로 보관하고(구글 드라이브), 기기에서 불러온다.
- 결과지는 「결과지에서 가릴 말」 목록과 메일·전화번호 형식을 자동으로 가린다.
- 검색엔진 수집 제외: `robots.txt`, `noindex`.
